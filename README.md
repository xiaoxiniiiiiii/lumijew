# Rubaoge Wholesale Accessories

React + Vite storefront prototype for a women's accessories wholesaler.

## Start

```sh
npm i
npm run dev
```

## Important setup notes

- Product images in `public/products` are original, unbranded AI-generated WebP assets. The generated contact sheets are cropped into individual product photos.
- Product prices and MOQ are editable sample wholesale offers in `src/catalog.js`. Confirm supplier costs, materials, stock, shipping and tax before accepting real orders.
- PayPal/card choices and order submission are front-end demonstration UI only. A real redirect/payment requires a merchant account and a secure server-side gateway integration.
- The admin panel is a local prototype without a database or real authentication. Change its demo credentials before any public deployment.
- Replace or confirm legal wording with qualified counsel before publishing. Company contact details are supplied by the site owner; company identity, address, email and phone must be checked for legal use.
